# P5 — Inventory (reagents, consumables, tidy-up) in `modules/inventory`

**Goal.** Move the inventory into `modules/inventory/` behind the P4 interface, with no change in behaviour.
Along the way, pull the shared bits it uses (git runner, accent folding, label printing) into clean base
utilities. Plan: §8.

**Before you start:** P4 merged.

## Rollback

Switch to the previous release branch and rename `data/reagents.migrated-<date>` back. The GitHub repository is
the master copy anyway: a fresh clone loses only edits that weren't pushed yet, so sync before switching.
