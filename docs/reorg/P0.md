## Found along the way

- **`job-info.txt` mixes languages.** Its headings are English, but its **Settings** section is in the language
  of the thread that writes the backup (the server default, Polish), not the runner's. The cause is that
  `meta.json` doesn't record the runner's prefs (see FORMATS.md §1).
  - The fixture keeps this as v0 really wrote it.
  - **Fixed on 2026-11-07** (owner's decision: English is the default; files on disk are always English; only
    the interface is translated). Stored jobs run in English, `job-info.txt` is written in English, and
    results are translated when shown (with a per-job phrase book). See FORMATS.md §1 "Language".
